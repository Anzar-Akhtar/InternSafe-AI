InternSafe AI multipage website
Theme: #0B0F14 + #C0FF3E with purple highlights.
Pages:
- index.html: Home
- check-job.html: input chooser
- url-check.html: separate URL check page
- text-check.html: separate text analysis page
- screenshot-check.html: separate screenshot page
- how-it-works.html
- about.html
- safety.html
- contact.html
Shared assets: style.css and script.js

Run:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html with Live Server, or double-click index.html.
Images load from Unsplash, so internet is needed to show them.
The forms are front-end demos only. Real NLP, OCR, URL reputation checks, company verification,
and risk scoring require a connected and evaluated backend. The contact form does not send data.
